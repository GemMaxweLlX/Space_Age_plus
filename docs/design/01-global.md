## Планеты

### Исследование планет

#### Уровень 1 — Телескоп

- Строится на Наувисе, открывает ближайшие тела — только силуэт
- Открывает технологию спутника 1 поколения

#### Уровень 2 — Спутник 1 поколения

- Ненадёжный, падает после работы. Шанс найти — не гарантия.
- При успехе — название и расстояние, детали скрыты
- Каждый запуск — прогресс к спутнику 2 поколения
- Стандарт: 10 запусков. Хардкор: 30-50, меньше шанс, быстрее падает.

#### Уровень 3 — Спутник 2 поколения

- Надёжный, постоянный. Открывает полные детали планеты.
- Разблокирует технологии полёта к планете.

#### Статус планеты и технологии

| Статус | Технологии |
|---|---|
| Не найдена | Скрыты полностью |
| Найдена спутником 1 | Видны названия, заблокированы |
| Разведана спутником 2 | Технологии полёта разблокированы |
| Посещена | Все технологии планеты доступны |

## Кислород

### Система кислорода

#### Атмосферный коллектор

Собирает местный воздух. Свой рецепт для каждой планеты. Не работает без атмосферы.

#### Генератор кислорода

Производит из ресурсов. Работает везде. Основная постройка там где нет атмосферы.

#### Распределитель

Создаёт пузырь с воздухом вокруг. Небольшая зона. Нужно несколько для большой базы.

#### Без кислорода

- Постепенно теряет здоровье
- В чате: "Неисправная система жизнеобеспечения"
- 3 настройки скорости: медленно / среднее / быстро
- 3 настройки объёма баллона. У каждого игрока своя система.

#### По планетам

| Планета | Решение |
|---|---|
| Наувис | Не нужно |
| Вулканус | Только генератор |
| Фульгора | Коллектор + фильтр |
| Глеба | Коллектор + биофильтр |
| Аквило | Коллектор + концентратор |
| Solaris | Только генератор |
| Echaris | Коллектор + ЭМИ-фильтр |
| Aquara | Коллектор + осушитель |
| Nivar | Коллектор + криоконцентратор |

## Мусор

### Космический мусор

- Выброшенные предметы становятся мусором на маршруте
- Маршрут делится на 10% отрезки со счётчиками
- Состав мусора зависит от выброшенного
- Мусор глобальный. Подобрал один — у остальных исчезает при посещении отрезка
- Подбирается сборщиком метеоритов из Space Age
- После 20+ ракет — обломки на орбите, могут падать на планету

#### По орбитам SA+

- Echaris — мусор электризуется
- Solaris — нагревается
- Aquara — биоплёнка
- Nivar — замерзает

#### Мотивация к уборке

- Больше мусора → чаще падения
- Подбор → ресурсы при дроблении
- Чистая орбита → меньше угроз

## Хардкор

### Хардкор-настройки

Каждый выбирает опции отдельно — не одна общая кнопка.

| Опция | Что меняет | Где |
|---|---|---|
| Агрессивные мобы | Атакуют без провокации | Aquara, Solaris |
| Постоянная буря | Без передышки | Aquara |
| Без доставки с платформы | Только местные ресурсы | Echaris, Nivar |
| Волны по таймеру | Механиты атакуют по расписанию | Echaris |
| Без нейтральной зоны | Убрать зону посадки | Echaris |
| Строгий кислород | Быстрее умирать без кислорода | Все планеты |
| Только дешифратор | ЛЛК не работает | Глобально |
| Спутник 1 поколения | 30-50 запусков, меньше шанс | Глобально |

## Захват ульев

### Захват ульев SA+

#### Механика

Глеба открывает базовую технологию (ваниль). Каждая планета SA+ — технология "Перекалибровка захватчика: [планета]". Снаряд в ракетницу → выстрел в гнездо → захват. Без биофлюса теряет здоровье и возвращается к врагам.

| Планета | Гнёзда | Дроп | Биофлюс |
|---|---|---|---|
| **Solaris** | Скорч, Магмар | Чешуйки, лавовые сгустки | Биофлюс Глебы + термит + магматит |
| **Aquara** | Рябь, Прибой | Ядовитые железы, панцири | Биофлюс Глебы + соль + водоросли |
| **Nivar (поверхность)** | Вьюга | Криопанцирь | Биофлюс Глебы + криолит + руда |
| **Nivar (пещеры)** | Иней, Сталагмит | Криожелезы, шипы | Биофлюс Глебы + криолит + тёмный лёд |
| **Echaris** | — | — | Механиты не живые, захвата нет |

> **Важно:** Крупные одиночки (Молтен, Бездна, Ледяной страж, Бездонный) — без гнёзд. Только убить для дропа.
