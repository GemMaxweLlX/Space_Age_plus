# Обзор

## Все модули Space Age+

### Концепция

Модульный мод для Factorio DLC Space Age. Каждый модуль устанавливается отдельно. Хардкор-настройки опциональны и выбираются индивидуально.

### Модули

- **space-age-plus-debris** — Космический мусор, все маршруты — `Идея готова`
- **space-age-plus-echaris** — Спутник Фульгоры, Механиты — `Идея готова`
- **space-age-plus-solaris** — Планета у Солнца, лава — `Идея готова`
- **space-age-plus-aquara** — Спутник Глебы, водный мир — `Идея готова`
- **space-age-plus-nivar** — Спутник Аквило, лёд и пещеры — `Идея готова`

### Глобальные механики

**Исследование планет** — туман войны, телескоп, спутники 2 поколений

**Система кислорода** — генератор, распределитель, коллектор

**Переосмысление технологий** — скрытое дерево, тех данные, дешифратор, ЛЛК

**Дневник инженера** — журналы, инопланетные данные, комментарии

**Захват ульев SA+** — перекалибровка для каждой планеты

**Система жидкостей высокого класса** — трубы, помпа Mk2, сверхпрочный насос
